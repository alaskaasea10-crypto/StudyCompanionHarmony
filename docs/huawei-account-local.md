# 华为账号本机档案（待真实授权验收）

## 已实现

- 原生 Account Kit `HuaweiIDProvider.createLoginWithHuaweiIDRequest`，随机 state 与回调校验。
- 仅使用新鲜原生回调 OpenID 的 SHA-256 作为本机档案命名空间。不持久化或日志打印 OpenID、ID Token、授权码或密码。
- 游客保持原 preferences 名称，旧记录原地保留。账号分别存学习快照、题库记录和视频收藏/观看标记。
- 首次授权明确选择复制游客数据或空档案；已初始化的账号不被覆盖；准备标记最后写入，失败可重试。
- 从“我的 → 账号与游客数据”进入；切换前暂停专注并检查保存结果，页面重新挂载以清除旧内存状态。
- 冷启动回到游客；再次打开账号档案需要原生授权。账号模式回前台重新检查系统账号，失效或变化时遮蔽内容。
- 退出只清理应用会话，不退出手机华为账号，不删除档案。
- 为避免账号资料暴露，账号模式不向卡片和通知发送学习内容。游客保留原功能。切换时清理通知和卡片。
- 迁移可能引用游客头像，因此不再无条件删除旧头像文件。后续需增加带引用检查的档案删除/空间清理。

## 尚未实现

云端会话、服务端 ID Token 校验、云同步、跨设备恢复、账号注销/档案删除、正式上架的完整账号合规验收。本机档案分区不是加密保险箱，不能用此实现替代服务端鉴权。

## 配置与部署阻塞

1. 应用级 Client ID 尚待核实。用户发来的值与较早项目级截图相同，未写进 module.json5。
2. 官方当前说明：应用 Client ID 与 APP ID 相同时无需额外配置；不同时在 entry/module.json5 的 metadata 配置 client_id。不要使用项目级凭据。
3. 旧模拟器应用为未签名调试版本，签名版覆盖安装返回 9568332（sign info inconsistent）。没有卸载或清除旧数据。
4. 未签名调试包仅用于界面检查，不能据此声称真实账号登录成功。下一步使用干净模拟器/真机安装签名包进行授权测试。

## 验证

- `scripts/test-account.cjs`：native 回调替身、state/取消、命名空间隔离、迁移与失败重试、不覆盖既有账号、前台账号变化、游客返回。
- 原有六组本地测试通过；签名 HAP 构建通过（存在 API 异常处理提示警告，调用方有 catch）。
- 模拟器未签名界面可启动、显示账号入口和登录页，旧 25 分钟与 2/2 任务记录仍在；没有提交真实授权。
