# 本地学习档案说明

## 当前比赛版本的真实行为

- 应用入口 `AppRoot` 直接加载 `Index`，当前没有启用华为账号登录或云端账号会话。
- 昵称、专业、学习目标、任务和学习记录保存在本机 `learner_profile` Preferences 快照中。
- 首次启动需要用户在 `ProfileSetupPage` 明确完成学习档案；保存后由 `StudyRepository` 持久化，重启时恢复。
- `ProfilePage` 展示当前本地档案中的昵称。重新设置学习档案只把初始化状态改为未完成，不会静默清空已有昵称。
- 云端 Agent 接口不是用户档案数据库，也不提供账号同步、跨设备恢复或身份认证。

## 当前未启用的旧实现

仓库仍保留 `AccountSession.ets` 和 `AccountArchive.ets` 作为历史代码，但当前 `AppRoot` / `Index` 没有导入或调用它们。比赛版本不能据此声称已经提供：

- Account Kit 登录；
- 账号与游客数据分区；
- 云端账号会话或服务端 Token 校验；
- 跨设备同步、账号注销或档案删除。

如比赛后重新启用账号能力，应先重新完成真实签名、Client ID、授权回调、隐私合规和真机验收，不能仅恢复旧入口。

## 验证

`scripts/test-account.cjs` 当前验证：

- 新安装没有伪造的已完成档案；
- 用户明确保存后，昵称、初始化状态和真实 taskId 可持久化并在重启时恢复；
- 持久化失败时回滚，不覆盖已有快照；
- 活动入口不依赖旧 `AccountSession`；
- 重置学习档案不会静默删除昵称。
