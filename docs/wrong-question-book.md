# 错题本与待复测清单

入口：学习 → 题库 → 选择专题 → 错题本。

- 自动从已有作答记录整理，按专题、知识点显示，不迁移或删除旧记录。
- 显示最近一次错误选项、正确答案、解析、累计错误次数。
- 默认待复测清单，可切换全部历史；看解析不改变状态。
- 原题订正：开启包含原题的三题小测，仍通过原来的保存流程提交答案。
- 换题验证：最后一次出错以后首次作答的同知识点不同题，最近回答正确才计入。旧题重复答对不冒充新题证据。
- 原题订正、换题验证分别展示，两者都有后移出待复测，历史保留；再次出错会重新进入清单。
- 未完成小测优先续答，不覆盖；新题用完后只作为复习，不能伪造新题验证。

全部离线推导，不增加云请求，不给原有掌握分加分，不安排系统通知。原始记录没有逐题时间戳，因此界面不展示虚构的答题日期。
