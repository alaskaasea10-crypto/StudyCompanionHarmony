# 统一学习行动与精简入口（2026-09-11）

## 本轮实现

- 首页默认只展示当前目标、一项行动、预计时间、一个主按钮。原因和完成标准默认折叠，移除独立的“接下来”长文区。
- 学习页顶部用同一决策提供“接着学”，四个原有模块放在“需要时再找”之下。
- LearningActionService 同时服务首页、学习页、桌面卡片；通知读取该卡片的同一行动。决策检查正在进行的专注、待提交结果、当天实际预算、课程空档（课前留 5 分钟）以及暂缓反馈。
- “30 分钟后”暂缓当前建议 30 分钟，“今天跳过”暂缓到北京时间次日；不删除任务，可恢复，状态保存在账号隔离的原学习快照内。
- 快照写入串行化，使用 saveChecked；失败会在首页提示并提供重试，不清空旧档案。
- TaskOutcomeService 区分 studying / focused / submitted / verified。结束计时仅记录 focused；资料、规划、通用产出通过短文本和自查确认提交，明确不计作知识掌握；题库阶段需要晚于本轮投入的新题证据，三个能力均达到初步掌握；小测只代表本次任务验证。
- 同阶段多项关联任务全部完成后才推进阶段。普通 Agent 重排保留其他目标、手动/视频/题库任务、已开始任务和结果记录；新任务保留当前目标与阶段关联。
- Agent 上下文传入真实多目标和阶段，使用当前优先目标的科目、期限和统一剩余预算。

## 不夸大能力的边界

- 账号模式原有隐私限制仍保留：桌面显示通用入口，不向系统通知暴露学习内容。
- 通知仍由已有的应用进入后台事件触发；本轮完成建议暂缓、旧提醒取消及下次触发重算，**没有增加应用被杀死后仍能准点触发的后台闹钟**。“30 分钟后”是推荐冷却时间，不保证系统准点推送。
- 课表使用现有星期/起止时间模型，不新增教学周、临时调课或跨日课程能力。
- 自查完成不是自动评分；单次小测不是整门课程掌握。原有历史完成记录不追溯改写。
- 题库专题仍为现有 3 个专题；没有扩充内容或声称覆盖全部大学课程。
